# Estudos com a XIAO ESP32-C6

Repositório destinado ao desenvolvimento de estudos, experimentos e protótipos utilizando a placa **Seeed Studio XIAO ESP32-C6** no contexto do projeto de divulgação da área de Telecomunicações do **IFSC Câmpus São José**.

## Sobre o projeto

O projeto busca criar um ambiente interativo para divulgação dos cursos da área de Telecomunicações.

A proposta envolve a representação de componentes de um sistema de comunicação, como satélites, antenas terrestres e enlaces de comunicação, permitindo que os participantes interajam com esses elementos por meio da transmissão e recepção de mensagens.

Com isso, pretende-se apresentar conceitos básicos de Telecomunicações de forma prática e experimental, aproximando estudantes do ensino fundamental e médio das tecnologias encontradas na área.
